# 061 — A name loses what can hide or reorder a line; a row beside an address begins with the address

**Context.** `pairing.SanitizeName` cleans every name that crosses a pairing: a Hub's name from a discovery answer (anyone on the network can send one) and from the handshake, a device's name on the Hub, and on the desktop the vault names a person types or the Hub lists. It dropped the C0 controls and DEL only (#292). U+2028 broke the line in a list, U+202E reversed what followed, a direction mark moved an address standing beside the name, and U+009B starts a terminal sequence. The two terminal lists of Hubs (`vaultsync pair`, `vaultsync-hub pair`) printed the name first and the address after it, and `vaultsync-hub pair` printed and stored the Hub's name from the handshake as it came.

**Decision.** (1) `SanitizeName` drops control characters (C0, DEL, C1), format characters (Unicode category Cf) and line and paragraph separators (Zl, Zp). It trims after dropping, and again after the cut to 64 bytes. (2) The joiners U+200C and U+200D stay inside a name and go at its ends. (3) A terminal's row for a Hub is `join.HubRow`: the address, a space, a left-to-right mark (U+200E), a dash, the name — the shape of the menu's rows (056). The line for the one Hub that answered keeps its words and gets the mark after the quoted name. (4) `vaultsync-hub pair` cleans the Hub's name from the handshake before it prints and stores it. The menu keeps its own, stricter filter (056): it can sit beside an older agent.

**Why.** A code goes to the Hub a person picks from that list (045), so a row must not be able to show another row's address as its own. The address is the one field an answer cannot write; behind it a name can claim anything and move nothing. Laid out with macOS's text engine, the old rows drew the address before a Hebrew or Arabic name and, where a line's direction follows its first letter, the whole row from the right; the new rows read the same either way. U+200E and not an isolate: the Linux console prints nothing for it, and it is the mark the menu already uses. The joiners cannot reorder or hide anything, and the names people give their own vaults and devices are written with them — a Persian plural with U+200C, an emoji made of two with U+200D. Nothing both ends must agree on holds a name: the key exchange runs on the code alone, devices are matched by their ID, and a new vault's name is compared as the device sent it. Builds with and without this change pair with each other as before.

**Rejected alternatives.** Dropping the joiners as the menu's rows do: it changes names people chose, for nothing a joiner can do to a line. Keeping only what Go calls printable (`unicode.IsPrint`): that drops every character newer than the toolchain's Unicode tables, new emoji among them, and every space but U+0020. Keeping the name first and wrapping it in isolates (U+2068 … U+2069): a console that knows neither prints two unknown characters per row, and a name could still draw an address column of its own before the real one. Cleaning in each caller: the Hub, the desktop agent and the iPhone's bridge link this one function.
