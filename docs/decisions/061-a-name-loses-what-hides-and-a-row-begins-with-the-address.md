# 061 — A name loses what can hide or reorder a line; beside an address, the address comes first

**Context.** `pairing.SanitizeName` cleans the names that cross a pairing: a Hub's name from a discovery answer (anyone on the network can send one) and from the handshake, a device's name on the Hub, and on the desktop the name typed for a new vault. It dropped the C0 controls and DEL only (#292). U+2028 broke the line in a list, U+202E reversed what followed, a direction mark moved an address standing beside the name, and U+009B starts a terminal sequence. The terminal lines that show a Hub (`vaultsync pair`, `vaultsync-hub pair`) printed the name first and the address after it, and `vaultsync-hub pair` printed and stored the Hub's name from the handshake as it came.

**Decision.** (1) `SanitizeName` drops control characters (C0, DEL, C1), format characters (Unicode category Cf) and line and paragraph separators (Zl, Zp). It trims spaces after dropping, and again after the cut to 64 bytes. (2) Two kinds of format character stay: the joiners U+200C and U+200D, and the tags of an emoji flag where they follow U+1F3F4. A name of spaces and joiners alone is the empty string. (3) The pairing client cleans the Hub's name in every answer it hands out, so no caller has to remember. `vaultsync-hub pair` gives a Hub whose name cleans to nothing the default name. (4) A terminal's line for a Hub is `join.HubRow`: the address, a dash, a left-to-right mark (U+200E), the name — in the list of several and in the line for the one that answered. (5) With `--create`, the desktop agent searches the Hub's catalogue for the cleaned name as well as the typed one.

**Why.** A code goes to the Hub a person picks from that list (045), or to the only one that answered, so a line must not be able to show another address as its own. The address is the one field an answer cannot write; behind it a name can claim anything and move nothing. Seen in macOS Terminal and laid out with macOS's text engine: the old lines drew the address behind a Hebrew or Arabic name with the name's digits over it, and from the right where a line's direction follows its first letter; the new ones begin with the address either way. U+200E and not an isolate: the Linux console prints nothing for it. It stands at the name, not at the address as in the menu's rows (056): Terminal draws it as a blank, and an address copied with the blanks behind it must stay an address. The joiners and a flag's tags cannot reorder or hide anything, and names people give their own vaults and devices are written with them — a Persian plural, a letter's form at the end of a word, an emoji made of two, the flag of Scotland. The Hub resolves the name it is sent like any selector, so a new vault's name that differed from an existing one only by what cleaning drops was taken for new on the desktop and joined the existing vault on the Hub. Nothing both ends must agree on holds a Hub's or a device's name: the key exchange runs on the code alone, devices are matched by their ID, and the Hub compares a vault's name as it was sent. Builds with and without this change pair with each other as before.

**Rejected alternatives.** Dropping the joiners as the menu's rows do: it changes names people chose, for nothing a joiner can do to a line. Keeping only what Go calls printable (`unicode.IsPrint`): that drops every character newer than the toolchain's Unicode tables, new emoji among them, and every space but U+0020. Keeping the name first and wrapping it in isolates (U+2068 … U+2069): a console that knows neither prints two unknown characters per line, and a name could still draw an address of its own before the real one. Chasing every character that draws nothing (a filler, a blank Braille cell) or draws too much (stacked combining marks): no category holds them, and behind an address they hide nothing. One filter for the menu and the terminals: the menu links no Hub package (048) and can sit beside an older agent, so it keeps its own, stricter one.

**Not covered.** The one-line refusal for several Hubs without a terminal keeps its words, "name at address" (056: an older menu shows them). A vault's label as the Hub lists it is cleaned in the desktop's menu row only; the lines after the choice, the folder proposed for it and `vaultsync-hub pair` show it as it came. Other format characters go with the rest, the Mongolian vowel separator and the Arabic number signs among them.
